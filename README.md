# Kanish S — Portfolio

A responsive personal portfolio for Kanish S, a Java Backend Engineer focused on low-latency trading, banking, payments, and distributed systems.

## Stack

- SvelteKit
- TypeScript
- Tailwind CSS
- Static adapter for fast deployment

## Development

```bash
npm install
npm run dev
```

Create a production build with `npm run build`.

## Content

Portfolio content is centralized in `src/lib/data.ts`. Professional case studies intentionally summarize proprietary work without exposing confidential implementation details.
